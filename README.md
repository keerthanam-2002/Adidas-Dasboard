# Adidas-Dasboard
Adidas Sales Dashboard is an interactive Power BI dashboard designed to analyze Adidas sales performance, revenue trends, product categories, retailers, and regional insights. It transforms sales data into clear visualizations and actionable business insights to support data-driven decision-making.
